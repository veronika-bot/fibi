# Промт для реализации кабинета родителя в ФИБИ

## Контекст
ФИБИ — платформа для подготовки к ОГЭ и ЕГЭ с возможностью занятий с репетиторами. Кабинет родителя позволяет отслеживать прогресс ребенка, управлять оплатой и взаимодействовать с репетиторами и другими родителями.

## Основной флоу

### 1. Регистрация и привязка

#### Регистрация родителя:
- Email / номер телефона
- Пароль (с валидацией)
- ФИО родителя
- Номер телефона
- Подтверждение email или SMS

#### Привязка ученика:
- Родитель вводит **код из личного кабинета ученика** (уникальный, временный)
  - Код должен быть 6-8 символов (буквы+цифры), действителен 24-48 часов
  - Ученик может найти код в своем кабинете в разделе "Настройки → Доступ родителя"
- Система автоматически связывает профиль родителя с профилем ученика
- Один родитель может быть привязан к нескольким ученикам
- Один ученик может быть привязан к нескольким родителям (для 2 опекунов)

#### Разрешения:
- Родитель видит полный прогресс ученика
- Может оплачивать подписку и занятия
- Не может менять настройки профиля ученика (только просмотр)
- Может отписать уведомления, но не может отключить видимость данных

## Структура кабинета

### Основные вкладки:

1. **Главная** (вместо "Dashboard")
2. **Прогресс** (детальный)
3. **Репетиторы**
4. **Домашние задания**
5. **Чат**
6. **Оплата и баланс**

## 1️⃣ Вкладка "Главная"

### Содержание:
- **Карточка статуса подписки**
  - Текущий тариф (Свободный / Самостоятельная подготовка)
  - Дата истечения подписки
  - Кнопка "Продлить" или "Купить"
  - Оставшееся время (дней)

- **Карточка прогресса ученика** (подтягивается из личного кабинета автоматически)
  - Выбранный экзамен (ОГЭ / ЕГЭ база / ЕГЭ профиль)
  - Класс и школа (если заполнено)
  - Текущий уровень готовности (0-100%)
    - Рассчитывается: (пройденные темы / все темы) * 100
  - Прогресс по основным темам (прогрессбары)
    - Дроби и проценты: 92%
    - Уравнения: 65%
    - Геометрия: 28%
  - Серия занятий (дней подряд)
  - Кнопка "Подробнее" → ссылка на вкладку "Прогресс"

- **Карточка активных репетиторов**
  - Список репетиторов, работающих с учеником
  - Аватар, имя, предмет
  - Дата последнего занятия
  - Кнопка "Написать" → открыть чат

- **Карточка напоминания об оплате** (если необходимо)
  - "Подписка истекает через 3 дня" или "Подписка истекла"
  - Кнопка "Оплатить сейчас"
  - Цвет: желтый (вскоре) или красный (истекла)

- **Карточка баланса на платформе**
  - Текущий баланс: X ₽
  - История последних платежей (3-5 записей)
  - Кнопка "Пополнить баланс"
  - Кнопка "История всех платежей" → вкладка Оплата и баланс

- **Быстрые ссылки**
  - "Купить занятие с репетитором"
  - "Посмотреть домашние задания"
  - "Связаться с поддержкой"

### Дизайн:
- Использовать цветовую схему ФИБИ (Yale #0D3B66, Lemon #FAF0CA)
- Карточки с тенью и hover эффектом
- Адаптивный layout (2 столбца на desktop, 1 на мобиле)
- Иконки SVG для каждой карточки

## 2️⃣ Вкладка "Прогресс"

### Содержание:

- **Статистика ученика**
  - Дата регистрации
  - Дней на платформе
  - Всего решено задач
  - Средний процент правильных ответов
  - Текущая серия занятий

- **Карта знаний** (если доступна в тарифе)
  - Граф связей между темами
  - Зеленые узлы = усвоена тема
  - Желтые узлы = в процессе
  - Красные узлы = не начиналась
  - Клик по узлу = детали по теме

- **Прогресс по темам** (детальный список)
  - Таблица или список с колонками:
    - Название темы
    - Статус (Усвоена / В процессе / Не начинали)
    - Процент выполнения
    - Дата начала
    - Дата завершения (если завершена)
    - Кол-во правильных / всего попыток

- **История прогресса** (график)
  - График "Прогресс со временем" (линейный график по дням)
  - X-ось: даты, Y-ось: процент выполнения
  - Фильтр: за неделю / месяц / всё время

- **Демоварианты**
  - Список пройденных демовариантов
  - Результат каждого (X/26 заданий)
  - Дата прохождения
  - Лучший результат выделен зеленым

---

## 3️⃣ Вкладка "Репетиторы"

### Содержание:

- **Список активных репетиторов ученика**
  - Аватар, ФИ, предмет
  - Рейтинг (звезды)
  - Уровень классификации (Опытный / Эксперт)
  - Дата начала работы с учеником
  - Кнопка "Написать" (открыть чат)
  - Кнопка "Профиль" (просмотреть полный профиль)

- **Информация по каждому репетитору** (при нажатии):
  - ФИ, аватар, рейтинг
  - Описание, опыт, специализация
  - Стоимость занятия (X ₽/ч)
  - График доступности (дни и время)
  - Кол-во занятий с учеником
  - Статистика: среднее время проверки, процент учеников на 4-5

- **Каталог всех репетиторов** (отдельная кнопка)
  - Таблица / карточки всех репетиторов на платформе
  - Фильтры: предмет, уровень, рейтинг, стоимость
  - Кнопка "Записаться на занятие"

- **История занятий с каждым репетитором**
  - Таблица:
    - Дата занятия
    - Статус (Запланировано / Проведено / Пропущено)
    - Время (начало-конец)
    - Оценка ученика (звезды)
    - Комментарий репетитора

- **Запись на новое занятие** (кнопка)
  - Выбор репетитора из списка или каталога
  - Выбор даты и времени
  - Подтверждение оплаты

---

## 4️⃣ Вкладка "Домашние задания"

### Содержание:

- **Список всех домашних заданий**
  - Фильтры:
    - По статусу (Новое / В процессе / Выполнено / Просроченное)
    - По дате
    - По репетитору

- **Карточка задания**
  - Название задания
  - Репетитор (аватар, имя)
  - Описание / условие задания
  - Дата выдачи
  - Срок выполнения
  - Статус выполнения (процент или чекбокс)
  - Кнопка "Посмотреть в личном кабинете" (ссылка в кабинет ученика)

- **Статистика по ДЗ**
  - Всего выдано заданий: X
  - Выполнено вовремя: Y (Z%)
  - Средний балл за ДЗ: X/10

- **Напоминание о просроченных ДЗ**
  - Выделено красным
  - Есть кнопка "Напомнить ученику"

---

## 5️⃣ Вкладка "Чат"

### Содержание:

- **Список чатов**
  - Чаты с репетиторами (работающими с учеником)
  - Чат с группой "Родители и репетиторы" (если ученик подписан)
  - Общий чат всех родителей
  - Поиск по чатам

- **Интерфейс чата**
  - История сообщений
  - Поле ввода сообщения
  - Кнопка прикрепления файлов
  - Смайлики / эмодзи
  - Уведомления о новых сообщениях

- **Групповые чаты**
  - Родители могут обмениваться опытом в отдельном чате
  - Модератор (администратор или старший родитель)
  - Правила чата (нельзя продавать, только полезное содержание)

- **Уведомления**
  - Родитель может выбрать, от каких событий получать уведомления
  - Новое сообщение от репетитора
  - Напоминание об оплате
  - Изменение прогресса ученика

---

## 6️⃣ Вкладка "Оплата и баланс"

### Содержание:

- **Текущий баланс**
  - Большая цифра текущего баланса: X ₽
  - "На счете осталось" или "Счет исчерпан"
  - Статус подписки

- **Пополнение баланса**
  - Кнопка "Пополнить баланс"
  - Выбор суммы (предзаполненные варианты: 500, 1000, 2500, 5000)
  - Или ввод произвольной суммы
  - Способы оплаты:
    - Карта (Visa, Mastercard)
    - Яндекс.Касса (если используется)
    - Сбербанк (если используется)

- **История платежей** (таблица)
  - Дата
  - Описание (Пополнение / Списание за подписку / Оплата занятия / Возврат)
  - Сумма (зеленая для входящих, красная для исходящих)
  - Статус (Успешно / Ожидание / Отклонено)
  - Детали (кнопка для просмотра)

- **Активные подписки**
  - Текущая подписка (Самостоятельная подготовка / Свободная)
  - Стоимость: 679 ₽/месяц (или 0 ₽)
  - Дата активации
  - Дата окончания
  - Кнопка "Продлить" или "Изменить тариф"

- **Оплата занятий с репетитором**
  - Предстоящие занятия с ценой
  - Кнопка "Оплатить сейчас" или "Оплатить позже"
  - После оплаты: счет выставлен и ждет подтверждения

- **Напоминания об оплате**
  - Карточка: "Подписка истекает через 3 дня"
  - Карточка: "У ученика есть просроченные платежи"
  - Кнопка быстрой оплаты

- **Скачать счет / квитанцию**
  - Для каждого платежа можно скачать PDF

- **Восстановление платежа**
  - Если платеж не прошел, показать ошибку
  - Кнопка "Повторить платеж"

## Интеграция с кабинетом ученика

### Автоматическое подтягивание данных:

- **Прогресс**: родитель видит **ровно то же**, что видит ученик
  - Процент выполнения
  - Серии занятий
  - Результаты демовариантов
  - История попыток
  - Карта знаний

- **Домашние задания**: если ученик получил ДЗ от репетитора, оно автоматически появится в кабинете родителя

- **Репетиторы**: список репетиторов, работающих с учеником, подтягивается из профиля ученика

### Синхронизация в реальном времени:

- Использовать WebSocket (Socket.io) для live-обновлений
- Когда ученик решает задачу → родитель видит обновление прогресса
- Когда репетитор выставляет оценку → родитель получает уведомление

## Функциональные требования

### Безопасность:

1. **Привязка ученика**:
   - Код должен быть хеширован в БД
   - Проверка на попытки brute-force
   - Log всех попыток привязки

2. **Доступ к данным**:
   - Родитель видит **только** данные своих привязанных учеников
   - Запрос: `GET /api/parent/progress/:studentId` проверяет, что studentId принадлежит одному из учеников родителя
   - Двухфакторная аутентификация опционально для вывода денег

3. **Оплата**:
   - Все платежные данные проходят через PCI DSS compliant систему
   - API ключи платежной системы хранятся в env переменных
   - Логирование всех платежных операций

### Производительность:

- Кэширование прогресса на 5-10 минут (он не меняется в реальном времени часто)
- Pagination для истории платежей и чатов (50 элементов на страницу)
- Lazy loading для больших списков

### Тестирование:

- Unit tests для расчета прогресса
- Integration tests для привязки ученика
- E2E tests для полного флоу: регистрация → привязка → просмотр прогресса → оплата

## Пример сценария использования

1. **Мама Ивана регистрируется** на платформе ФИБИ
   - Вводит email, пароль, ФИ, номер телефона
   - Подтверждает email через ссылку

2. **Привязывает Ивана через код**
   - Иван открывает свой кабинет → Настройки → "Добавить родителя"
   - Получает код: `AB3K7X`
   - Мама вводит этот код в своем кабинете
   - Система автоматически связывает их

3. **Мама видит главную**
   - Текущий уровень готовности Ивана: 58%
   - Серия: 7 дней подряд
   - Активный репетитор: Анна Петрова (математика)
   - Баланс: 0 ₽, подписка истекает через 5 дней

4. **Мама пополняет баланс**
   - Нажимает "Пополнить баланс"
   - Вводит 2000 ₽
   - Выбирает "Оплатить картой"
   - Платеж успешен, баланс теперь 2000 ₽

5. **Мама продлевает подписку**
   - Видит напоминание "Подписка Ивана истекает"
   - Нажимает "Продлить"
   - 679 ₽ списываются со счета (остаток: 1321 ₽)
   - Подписка продлена на месяц

6. **Мама смотрит прогресс**
   - Открывает вкладку "Прогресс"
   - Видит граф знаний: какие темы усвоены, какие в работе
   - Видит, что Иван хорошо учит "Уравнения" (92%), но плохо "Геометрию" (28%)
   - Видит демоварианты: лучший результат 88%

7. **Мама пишет репетитору**
   - Открывает вкладку "Чат"
   - Выбирает чат с Анной Петровой
   - Спрашивает: "Анна, почему Иван плохо решает геометрию?"
   - Анна отвечает с рекомендациями

8. **Мама видит ДЗ**
   - Открывает "Домашние задания"
   - Видит, что Анна выдала ДЗ: "Решить 10 задач по геометрии"
   - Срок: завтра
   - Иван уже выполнил 7 из 10
   - Мама может напомнить Ивану о оставшихся задачах
